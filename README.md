# nasa-space-x
This repo contains a tool for the 2026 NASA Space Apps Challenge (SPHEREx and PlanetX tracks). We use NASA open data and machine learning to analyze changes in the sky objects and present the results in an interactive, easy-to-use app. Built by Dovlet Gurbanov and Rahman Bazarov.
