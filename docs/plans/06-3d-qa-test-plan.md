- Drag to rotate: the hint fades after the first drag; auto-spin stops and resumes after 8 s idle
- ←/→ step the clock and Shift+←/→ rotate when the canvas has focus; keys are ignored inside form controls
- "Open in full player →" opens index.html?t=<slug>; Back returns to the same object and frame
- "Show as table" on the spectrum shows µm / value / error
