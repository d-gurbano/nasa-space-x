## Vision

### 10x Check
The 10x version is a public "time machine" for any point on the sky: type a name, see every SPHEREx season of it, with honest labels (wavelength, masking, predicted position) and pre-screened change candidates, so non-experts can tell real motion from instrument artifacts. In 24h the plan delivers that for 5 cached targets plus a Practice mode, with the manifest format ready for live any-coordinate fields.
