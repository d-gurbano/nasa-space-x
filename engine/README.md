# SpaceApps2026-Rewind (Team SpaceX - Rahman + Dovlet)

NASA Space Apps 2026, challenge "Planet X and SPHEREx".
Idea (draft): Rewind - when a new asteroid or comet is discovered, find it in older SPHEREx photos so its future path becomes much more certain.

Folders:
- data/01-new-objects-and-risk      new discoveries, JPL Scout/Sentry, close approaches
- data/02-orbits-and-observations   orbits, uncertainties, observation history, earlier sightings
- data/03-spherex-core              SPHEREx frame lists, docs, flags, wavelength maps, all-sky map tiles
- data/04-test-targets              the 5 challenge test targets
- data/05-composition-library       reference asteroid/comet spectra, sizes/albedos
- data/06-answer-keys-and-junk      known objects per frame, labeled satellite trails, star catalogs
- data/cutouts                      SPHEREx photo cutouts (Phase B)
- research/                         research pack and all agent reports
- notes/                            discussion notes and decisions
- code/                             scripts
- docs/                             source list and citations

Rules: public data only; no Chinese sources; every file listed in docs/SOURCES.md with link, credit, license, and US or partner origin.
